## Catalist

Catalist es una solución integral de gestión de ventas y facturación para la industria química. Nuestra plataforma intuitiva facilita la administración de productos, clientes y proveedores, permitiendo decisiones estratégicas en tiempo real.

### Características Principales
- Gestión avanzada de productos químicos
- Optimización de procesos y eficiencia operativa
- Informes detallados y análisis
- Seguridad y cumplimiento normativo
- Integración con sistemas empresariales
- Soporte y actualizaciones continuas

### Tecnologías Utilizadas
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: MongoDB, Node.js, Express
- Despliegue: Firebase Hosting


### Documentación

### Requisitos Previos
- Navegador web moderno (Chrome, Firefox, Edge, etc.)

### Uso
1. Accede a la [plataforma](https://catalist-a076a.web.app).
2. Inicia sesión: usuario: `admin`, contraseña: `admin`.
3. Navega por las secciones "Gestión", "Reportes", y "Facturas y Cotizaciones" para realizar las tareas necesarias.
